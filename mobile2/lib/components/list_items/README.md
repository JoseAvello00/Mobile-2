# List Items

O trabalho exige a implementação de **2 componentes**. Este projeto implementa
`ActionButton` e `TabBar` como os 2 componentes obrigatórios (ViewModel +
Component + Factory completos).

Esta pasta `list_items/` foi mantida na estrutura (conforme o quadro) como
ponto de extensão para um 3º componente futuro, seguindo exatamente o mesmo
padrão dos outros dois:

- `list_item_view_model.dart`
- `list_item_component.dart`
- `list_item_factory.dart`
